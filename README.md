# ⚛️ ReactorX — Frontend

> React 19 + Tailwind CSS 4 storefront for the ReactorX e-commerce platform.

[![React](https://img.shields.io/badge/React-19-61DAFB?logo=react)](https://react.dev)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-38BDF8?logo=tailwindcss)](https://tailwindcss.com)
[![Vite](https://img.shields.io/badge/Vite-Rolldown-646CFF?logo=vite)](https://vite.dev)

---

## ✨ Features

- Product browsing with category filtering
- Dynamic cart management (add, update, remove)
- Secure checkout flow integrated with Razorpay
- Responsive UI built with Tailwind CSS 4
- Fast builds powered by Rolldown/Vite

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React 19 | UI framework |
| Tailwind CSS 4 | Styling |
| Vite (rolldown-vite) | Build tool |
| Razorpay | Payment integration |

## 🚀 Run Locally

```bash
git clone https://github.com/binoremohapatra/ReactorX-Frontend.git
cd ReactorX-Frontend
npm install

# Set backend URL
echo "VITE_API_URL=http://localhost:8080" > .env

npm run dev
```
